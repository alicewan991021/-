# 記憶重生

《記憶重生》是一款以林敬偉第一人稱視角進行的劇情探索解謎遊戲。

## 目前版本

第一版可遊玩測試版，包含：
- 序章與臥室探索
- 連動齒輪機關（測試謎題）
- 廁所梳洗互動與鏡面水霧探索
- 敬偉筆記本、線索紀錄與瀏覽器存檔
- 手機觸控方向鍵與電腦鍵盤操作

目前先完成一段可實際遊玩的核心流程，其他房間與十關完整內容會在後續版本逐步加入。謎題文字與部分線索仍屬測試草案，正式內容以後續確認版本為準。

## 遊玩方式

- 電腦：方向鍵或 WASD 移動，點選房間物件互動。
- 手機／iPad：使用畫面上的方向鍵，或直接點選物件。
- 「筆記本」查看已整理的發現。
- 「存檔」將進度儲存在目前瀏覽器的 localStorage。

## 啟用 GitHub Pages

1. 開啟此 Repository 的 **Settings**。
2. 進入 **Pages**。
3. 在 **Build and deployment** 的 Source 選擇 **Deploy from a branch**。
4. Branch 選擇 **main**，資料夾選 **/(root)**，按 Save。
5. 等待 GitHub Pages 完成部署，再從 Pages 頁面開啟網站。

網站檔案位於根目錄的 `index.html`。GitHub Pages 首次部署可能需要一些時間。

## 設計原則

- 每個主要劇情節點都有三種結局方向的線索。
- 玩家解謎或生活操作失誤不會改變結局。
- 最終結局由玩家在大門輸入的密碼決定。
- 不使用好感度、懷疑值等數值系統。
- 以生活互動、探索、推理與第一人稱小說敘事交織呈現。
